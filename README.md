### 🫁 Pneumonia Detection with Deep Learning  
Ensemble-based CNN, MobileNetV2, and EfficientNetB0 models trained on X-ray images with Grad-CAM explainability.  
Achieved **96% accuracy** and **0.995 AUC**, deployed via Streamlit.  
🔗 [Repo](https://github.com/sarmi2325/Pneumonia_detection) | [Live App](https://pneumoniadetection-er8mvnqy9s9ejsr2g6wqjk.streamlit.app/)
